## 代码任务

### 任务 1：`frontend/app.py` —— Streamlit 工作台主文件

**五大区域：**

1. **对话区**（主区域）
   - 聊天历史（st.chat_message）
   - 流式输入（st.chat_input）
   - 引用标记点击 → 弹窗原文

2. **文档管理面板**（侧边栏上部）
   - 上传文档（st.file_uploader → POST /documents/upload）
   - 文档列表（GET /documents）
   - 索引进度条

3. **Agent 决策面板**（侧边栏中部）
   - 意图分类结果
   - 置信度分数
   - 改写次数
   - 检索命中数

4. **预设 Query 区**（侧边栏下部）
   - 15 条快捷按钮，覆盖 7 类文档

5. **状态栏**（底部）
   - API 服务状态 / 响应耗时 / Trace ID

### 任务 2：确保 API 对接

- `/chat/stream` → 流式对话
- `/agent/chat` → Agent 对话（带决策信息）
- `/documents/upload` → 文档上传
- `/documents` → 文档列表
- `/documents/{doc_id}` → 删除文档
- `/health` → 服务状态

## 差异化亮点

1. **引用弹窗**：点击 `[来源: XX 第X条]` → 弹出原文片段
2. **Agent 决策可视化**：实时显示意图/置信度/改写路径
3. **预设 Query**：15 条精心设计的演示问题，面试时点一下就能展示
4. **两列布局**：对话 + 管理面板分开，功能齐全但不乱
