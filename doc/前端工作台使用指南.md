## 一、💬 对话区（主区域）

### 1.1 发送消息
- 在底部输入框输入问题，按 **Enter** 发送
- 示例：「旅客行李箱摔坏了怎么赔？」

### 1.2 流式输出
- LLM 的回答会**逐字出现**，就像 ChatGPT 一样
- 等待过程中可以看到文字逐步生成

### 1.3 引用溯源（点击查看原文）
- 回答中会出现 `[来源: 文档名 第X条]` 标记
- 点击 **📎 引用溯源** 展开按钮 → 查看原文片段
- 每条引用包含：文档名、条款编号、章节标题、原文片段

### 1.4 模式切换
- ☑ **Agent 路由**：勾选后走 LangGraph Agent 智能决策
  - 自动判断意图（政策查询/操作指引/应急/不确定）
  - 检索不足时自动改写 Query 重试
  - 回答中包含改写次数和置信度
- 不勾选：走普通 RAG 直连，更快但无决策过程

### 1.5 Top-K 调整
- 输入框上方的数字输入框，控制检索返回的文档片段数
- 默认 5，范围 1~10
- 越大 = 更多上下文 → 回答更全面但更慢

## 二、📁 文档管理面板（侧边栏上部）

### 2.1 上传文档
1. 点击「上传民航文档」按钮
2. 选择 PDF / Markdown / TXT / DOCX 文件
3. 自动上传 → 解析 → 切片 → 向量化 → 写入 Qdrant
4. 成功后显示绿色提示

### 2.2 查看文档列表
- 点击「🔄 刷新文档列表」更新
- 显示：文件名 + 切片数量
- ✅ = 已索引，⬜ = 未索引

### 2.3 删除文档
- 点击文件名旁的 🗑 按钮
- 同时删除 Qdrant 向量 + BM25 索引 + 本地文件

## 三、🤖 Agent 决策面板（侧边栏中部）

### 3.1 决策流程图
发送消息后，面板以 ASCII 流程图展示 Agent 的决策路径：

```
          ┌──────────┐
          │  START   │
          └────┬─────┘
               │
          ┌────▼──────┐
          │ 意图分类  │ → 政策查询
          └────┬──────┘
               │
          ┌────▼──────┐
          │   检索    │ → 命中 5 条
          └────┬──────┘
               │
          ┌────▼──────┐
          │ 置信度评估│ → 85%
          └────┬──────┘
               │
          ┌────▼──────┐
          │ ✅ 生成回答│
          └───────────┘
```

### 3.2 指标卡片
- **置信度**：检索结果质量（0~100%），低于 50% 会触发改写
- **改写次数**：Agent 自动改写 Query 的次数（0/1/2）
- **检索命中**：返回的文档片段数量

### 3.3 决策分支说明

| 场景 | 意图 | 流程图表现 |
|------|------|-----------|
| 正常查询 | 政策/操作/应急 | 意图→检索→评估→生成回答 |
| 低置信度 | 政策查询 | 意图→检索→评估→🔄改写→重新检索→生成 |
| 2次改写仍低 | 政策查询 | 意图→检索→评估→降级兜底 |
| 不确定 | uncertain | 意图→直接降级兜底 |

## 六、演示流程（面试用）

### 推荐演示步骤（约 3 分钟）

**Step 1**：点 RAG 直连模式，发一个预设 Query
- 「旅客行李箱被摔坏了，赔偿标准是什么？」
- 展示：流式输出 + 引用溯源弹窗

**Step 2**：勾选 ☑ Agent 路由，发同一个问题
- 展示 Agent 决策面板：意图 = 政策查询，置信度 > 80%
- 对比 RAG 直连和 Agent 路由的结果差异

**Step 3**：发一个模糊问题
- 「箱子摔烂了怎么办？」
- 展示 Agent 的 Self-Reflection：置信度低 → 改写 Query → 重新检索

**Step 4**：发一个非业务问题
- 「今天天气怎么样？」
- 展示 Agent 降级兜底：意图 = uncertain → 告知不是业务问题

**Step 5**：展示文档管理
- 上传一个新文档 → 查看列表 → 发相关查询 → 验证检索成功

## 七、常见问题

### Q: 前端显示「服务异常」？
**A**: 后端 `python main.py` 没有启动，或启动失败。

### Q: 回答为空或报错？
**A**: 知识库为空，先上传文档。上传后在侧边栏检查文档列表是否显示 ✅。

### Q: 回答不相关？
**A**: 尝试：
1. 增大 Top-K（如 5 → 10）
2. 勾选 Agent 路由模式
3. 换一种更精确的问法

### Q: 流式输出卡住？
**A**: DeepSeek API 偶尔超时，等 10 秒，或检查 LLM API Key 余额。
